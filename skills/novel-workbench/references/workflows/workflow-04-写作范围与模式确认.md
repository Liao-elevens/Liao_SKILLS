# 工作流04：写作范围与模式确认

## 范围优先级

1. 用户明确的“第 N—M 章”
2. 用户明确的“完成某一卷”
3. 计划文件中尚未完成的活动范围
4. 全书未完成章节

范围两端均包含。`stopAfterScope` 为 `true` 时，范围末章审核完成后必须停止。

## 模式

- `serial`：默认模式，主 Agent 按章节顺序写作，最适合保持人物和悬疑连续性。
- `parallel`：仅在用户明确授权并具备并发工具时使用，章节范围不得重叠。

不再把特定平台的 Agent Teams 写进主流程；平台差异由运行环境自行处理。

## 模式确认后

将以下内容写入计划文件：

- `mode`
- `activeScope`
- `scopeHistory`
- `stopAfterScope`
- `projectStatus`

写作开始后，只要范围没有变化，就不再次向用户确认。

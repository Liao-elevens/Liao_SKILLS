# 工作流06：分卷审核与跨卷精修

## 卷末审核

活动范围内的章节全部写完后，依次执行：

1. 章节文件和计划路径检查
2. 字数与正文纯净检查
3. 角色、关系、时间、地点、资源和身体或人格状态检查
4. 概念首次解释和真相边界检查
5. 伏笔公平性、回收状态和卷末钩子检查
6. 主线、社会线、生活线和群像线节奏冷读
7. 局部精修，保留修改记录

审核报告写入 `05-写作过程/分卷审核/`，不写入 `正文/`。

## 跨卷审核

完成三个以上分卷或用户要求全书审核时，增加：

- 全书时间线和年龄、距离、资源算术
- 人物变化弧和关系反转
- 伏笔埋设到回收的证据链
- 终局信息是否提前泄露
- 群像是否被第一主角完全吞没
- 主题冲突是否在结尾真正落地

发现问题时先记录优先级：P0（逻辑断裂或严重泄密）、P1（连续性和节奏）、P2（语言和局部质感）。

## 结算

只有活动范围全部通过，才将该范围标记为 `completed`。子范围完成不能把整部小说标记为完成。

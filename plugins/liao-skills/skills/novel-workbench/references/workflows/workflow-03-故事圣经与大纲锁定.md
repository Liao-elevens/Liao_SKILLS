# 工作流03：故事圣经与大纲锁定

## 必备档案

根据题材生成以下文件：

- 角色档案：欲望、恐惧、缺陷、声音、关系和变化弧线
- 世界观设定：时间线、运行规则、资源、限制和代价
- 概念词典：术语、首次出现时的局部解释和读者已知程度
- 悬念与伏笔矩阵：线索、证据、误导、回收章和未回收风险
- 真相封存档案：作者知道但正文当前不能确认的内容
- 群像声音表：每个重要角色的注意点、语速、意象、盲区和禁用表达

## 大纲锁定

大纲至少包含：

- 全书主线和分卷功能
- 每章核心事件、人物选择、信息变化、场景、承接项和结尾状态
- 每卷必须回收、继续隐藏或升级的线索
- 社会线、生活线、人物线与主线的比例意图

确认后，将规划文件标记为 `locked`。写作过程中的实际偏差写入 `05-写作过程/逐章完成记录.md`，不直接覆盖锁定内容。

## 计划文件

使用 `写作计划结构规范.json`。章节的 `path` 必须指向 `正文/卷目录/章节文件.md`，机器状态只记录状态、字数、校验结果和最后更新时间。版本号记录在 JSON 内部的 `schemaVersion` 字段。

## 开始写作的门槛

以下项目未完成时，不开始批量写正文：

1. 第一卷或首批章节的章节规划已锁定。
2. 第一主角和主要群像已具备可写的声音与行为约束。
3. 读者当前知道什么、不能提前知道什么已经标记。
4. 活动范围和停止边界已经写入计划文件。
